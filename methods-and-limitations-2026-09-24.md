# TASO APP Explorer: Methods and Limitations

Publication version: 24 September 2026

This public page presents pilot analytical findings from TASO's APP Explorer project. It is designed to support exploration of published Access and Participation Plan content, including interventions, equality risks and targets.

## Scope

The public page reads only approved static datasets. It does not call a live AI service, expose unpublished APP documents or allow public upload of arbitrary files.

The interventions file contains the approved extract supplied on 24 September 2026. The EORR risks and targets file remains empty until an approved published extract is supplied:

- `data/interventions-2026-09-24.csv`
- `data/eorr-risks-targets-2026-09-24.csv`

## How information is presented

The page preserves provider, region, student group, lifecycle stage, category, intervention, intended outcome, evaluation approach, supporting quotation, page or section reference, confidence label, source document and APP identifier fields where available.

Missing values should remain blank in the source file. The public page presents missing information as “Not stated”.

## Appropriate use

The findings may support evidence reviews, evaluation commissioning, provider support, training, identification of recurring intervention types and future research questions.

The findings should not be used as provider rankings, performance scores or definitive claims about institutional practice.

## Limitations

The APP Explorer outputs are pilot findings and require human review before formal use. Classification confidence does not indicate provider quality. Quotations and classifications should be understood in the context of the original APP.

Absence from the dataset does not prove absence from an APP. Extracted records may reflect direct evidence, interpretation or both, depending on the approved source fields.
